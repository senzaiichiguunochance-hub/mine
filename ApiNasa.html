NASA API

このダッシュボードについて

NASAの公開APIを使って、宇宙や地球の最新データを体験できるページです。
現在は DEMO_KEY（共通の体験用キー）を使用しています。

DEMO_KEY は世界中の利用者と共有されており、次の制限があります。
・1時間あたり30回までのリクエスト
・1日あたり50回までのリクエスト
制限を超えると「OVER_RATE_LIMIT」というエラーになります。

エラーが出た場合は時間をおいて再試行するか、NASA公式サイトで 自分専用の無料APIキーを取得してください。
